# Dev Cheatsheets

**[Live demo →](https://oxayavongsa.github.io/ai-automation-portfolio/apps/dev-cheatsheets/)**

A mobile-first, tabbed syntax reference comparing core constructs (I/O, variables, control flow, loops, collections, functions) across **Python, JavaScript, SQL, Java, C++, and Bash**. Built as a study aid while completing structured-programming coursework (C++, Python) after an MS in Applied AI.

- Data-driven: one `DATA` object renders every card, so adding a language is a JSON edit
- XSS-safe rendering via `textContent`
- Sticky, swipeable tab bar; safe-area insets for phones

Vanilla JS · zero dependencies
