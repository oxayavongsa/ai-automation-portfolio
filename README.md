## Agents & scheduled workflows

| Project | What it does | Tech |
|---|---|---|
| [Bookkeeping Reconciliation Agent](agents/bookkeeping-reconciliation-agent/) | Cron-scheduled agent that reconciles QuickBooks to bank-statement PDFs, de-dupes with reversing JEs, applies owner rules, and returns a tax-ready review packet. No delete/send/file permissions | Claude agents · QuickBooks API · PDF parsing · cron |
| [Vehicle Deal Screener](agents/vehicle-deal-screener/) | Marketplace alert → LLM classifier → SMS. Texts only listings that clear a resale-profit and clean-title bar | Zapier · Claude · constrained outputs |

| [AI Video Ad Generator](agents/ai-video-ad-generator/) | Reusable prompt system for realistic 15s vertical commercials for local businesses | Seedance (text-to-video) · prompt engineering |
