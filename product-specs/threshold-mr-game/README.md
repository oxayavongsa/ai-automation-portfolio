# THRESHOLD: Mixed Reality Game Design Document

A full game design document for a room-adaptive mixed reality game on Meta Quest 3 / 3S, where a player's real home becomes the level and AI companions (with consent-gated voice and avatar cloning) fight beside them.

**[▶ Read the spec](https://oxayavongsa.github.io/ai-automation-portfolio/product-specs/threshold-mr-game/)** · October 2026

## What's in it

| Section | Highlights |
|---|---|
| Concept & lore | Horror + suspense + action + an emotional core; four factions that each power a level |
| Core loop & controls | Scan → breach → survive → discover → return home; hand tracking, body movement, whisper commands, gaze |
| Room-adaptive systems | MRUK anchor spawning, breach placement, furniture-aware hiding logic, occlusion, small-room mode |
| Secrets & replay | 9 layered secret types (room-seeded, time-based, rare drops, voice, co-op, cross-level, ARG meta-puzzle) |
| Multiplayer | Solo with AI companions, co-located via Shared Spatial Anchors, online via Photon Fusion / Normcore |
| AI companions | Photo/voice upload → avatar + cloned voice + personality card; live LLM dialogue; consent-selfie verification, takedowns, minors blocked |
| Monetization | Premium base + seasons + cosmetics + companion slots + a voice subscription that covers per-minute AI cost |
| Safety & legal | COPPA, likeness and digital-replica laws, voice-cloning verification, rating constraints, privacy |
| Roadmap | Gated phases from a WebXR prototype to a Unity vertical slice to publisher funding |

## Skills shown

Product design · systems design for spatial computing · AI feature design with responsible-AI guardrails (consent, likeness, minors) · unit economics for LLM/voice costs · phased, gated roadmapping
