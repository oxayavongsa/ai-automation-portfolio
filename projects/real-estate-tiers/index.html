Real Estate Pricing Tier Classification

Given beds, baths, lot size, living area, city and state, which pricing tier does a listing belong to? This project turns home pricing into a multi-class classification problem.

  • Data: the USA Real Estate dataset (Realtor.com), cleaned to 1,382,006 listings after outlier removal, split 80/20.
  • Best model: Random Forest, with 0.760 accuracy, 0.72 macro F1 and 0.894 AUC on 276K test listings.
  • Compared: KNN, Gradient Boosting, Naive Bayes, Logistic Regression and a Keras MLP.
  • Insight: mid-market homes were the hardest tier to separate, as expected for a band that overlaps both neighbors.
  • Course: AAI-501 Introduction to AI (University of San Diego), team project.
